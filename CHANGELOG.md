# Changelog

Номер пакета (`xconn_channel.__version__`) и версия провода — разные вещи.
В кадре `HELO` едет `PROTO_VERSION` из `xconn_channel/config.py`. У 1.0.0 он
по-прежнему `1`: смена номера пакета не ломает рукопожатие со стороной 0.4.

## 1.0.0 — 2026-09-30

Первая опубликованная версия. Состав — то, что уже принято на живом кабеле
(прогон 2026-09-22, приёмка первой сборки 2026-09-25).

- Полудуплекс с подтверждением кадра: `probe` 300 бод на рукопожатии, рабочий
  `base` 1200 бод, тона Bell 202, CRC и повтор. `stretch` 2400 выключен.
- Обратно — сетка VT100 (24×80, cp437): целиком, дельтой или кусками
  `SCREEN_PART`, не поток stdout и не растр.
- Файлы в обе стороны: `FILE_OPEN` / `FILE_DATA` / `FILE_CLOSE` и
  `FILE_GET` / `FILE_OFFER` / `FILE_PULL`, в REPL — `.put` / `.get`.
- Автономный установщик на USB-флешку (`py -m xconn_channel stick`): офлайн
  Python и `alsa-utils`, на сервере без интернета и без сборки.
- Пользователь `xconn` с passwordless sudo (`NOPASSWD:ALL`, без `!requiretty`).
- Один пакет на обеих сторонах: клиент Windows через winmm, агент Linux через
  ALSA (`hw:` / `plughw:`). Только стандартная библиотека, внешних зависимостей нет.
